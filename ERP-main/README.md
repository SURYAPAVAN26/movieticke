# 📌 Project Overview

The Movie Ticket Booking System is a web-based application developed to simplify the process of booking movie tickets online.

The system allows users to:
- Browse movies
- Select show timings
- Choose seats
- Book tickets
- Manage bookings

The project demonstrates full-stack web development concepts using Java technologies and database integration.

---

# 🎯 Problem Statement

Traditional ticket booking systems often involve:
- Long waiting times
- Manual seat management
- Poor user experience

This project aims to provide:
- Fast online booking
- Efficient seat management
- Secure booking system
- User-friendly interface
